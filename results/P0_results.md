## 1. R1-06：学习型数据集级静态权重基线

### 1.1 做法

对每个 (dataset, seed)：

1. 取 val 三成员预测 $\{p_i^{val}\}_{i=1}^{3}$ 与 $y^{val}$，在 3-单纯形上求解
   $$w^{\star}=\arg\min_{w\in\Delta^2}\ \frac{1}{N_{val}TC}\sum_{n,t,c}\Big(\sum_i w_i p_i^{val}[n,t,c]-y^{val}[n,t,c]\Big)^2 .$$
   实现为精确凸二次规划：枚举全部有效面（顶点/边/内部），每个面解等式约束最小二乘
   $[G_S,\mathbf 1;\ \mathbf 1^\top,0]\,[w_S;\lambda]=[b_S;1]$，
   取可行且 SSE 最小者（等价于 softmax 参数化收敛到的全局最优）。
2. **冻结 $w^{\star}$**，在 test 上计算 $\mathrm{MSE}_{test}(w^{\star})$。`w` 只见过 val，test 未参与任何选择。

对照：

* **SAWE**：`router_weights_test.npz` 的逐样本权重加权（行和已为 1）。
* **Equal**：三成员算术平均（即缓存中的 `static_ensemble`）。
* **Best single**：按论文 Table 9 的可复现口径——用 **3-seed 平均 val MSE** 选出一个成员，再报告该成员的 3-seed test MSE（mean±std）。这是协议允许的固定单成员基线。

### 1.4 结论（如实回答 R1-06）

* **SAWE 相对静态学习权重没有统计显著优势。** 数据集层面均值差 −1.02%（中位数 **+0.71%**，即 SAWE 略差）；SAWE 只在 2/6 数据集更好（exchange_rate、ETTh1），4/6 更差；18 个 (dataset, seed) 对中仅 8 个 SAWE 更好。Wilcoxon 数据集级 p = 1.00，配对 t 检验（18 对，存在种子伪重复）p = 0.21。
* 全部差异由 **exchange_rate** 驱动：该数据集逐种子的 val 最优成员与 test 最优成员排序翻转，静态权重退化为顶点（F / 混合 / FL），test MSE 波动 0.3809–0.4686；SAWE 因权重接近常数而避开了这个 val 过拟合。**去掉 exchange_rate 后，静态权重在其余 4/5 数据集上优于 SAWE（平均 +0.62%，正值表示 SAWE 更差），唯一例外是 ETTh1（−1.11%）**。
* 学到的权重经常落在单纯形边界（11/18 个种子至少一个分量为 0），说明“数据集级静态权重”本身在 3 成员、3 种子上并不稳定，不能作为单一强基线被引用。
* 等权在 4/6 数据集已优于 Best single（exchange、ETTh1、ETTh2、ETTm1），但在 ETTm2/Weather 上崩溃。
* SAWE 相对等权只在 ETTm2/Weather 等 **存在发散成员** 的数据集上大幅领先（−51%、−30%），其余基本持平（exchange 上还略差 +0.4%）。router 权重几乎不随样本变化（数据集内逐样本标准差 ≤ 0.041，exchange/ETTh2 ≤ 0.002），与审稿人“本质是数据集级非均匀权重”的判断一致。
* 因此，**不能把 SAWE 的收益归因于频谱感知的逐样本路由**；可归因的部分是“全局非均匀加权 + 压低发散成员”，而这一部分静态学习权重同样可以获得，甚至更稳。

## 2. R1-07：θ 敏感性与成员选择规则

### 2.1 做法

* 对每个 dataset，用 **val** 三成员 **3-seed 平均 MSE** 计算 $\rho=\text{worst}/\text{best}$。
* 对每个 θ：若 $\rho>\theta$ 则移除当前 worst，循环直到 $\rho\le\theta$ 或只剩 2 个成员。
* 决策固定后，用 **test** 预测评估：SAWE 为 router 权重在保留成员上按样本重新归一化后加权；Equal 为保留成员等权。**test 从未用于选择 θ 或成员**。
* θ 网格：1.05, 1.10, 1.15, 1.20, 1.25, 1.30, 1.40；θ=1.2 加粗。

## 3. R1-09 / R1-10：测试集分带口径与显式公式

### 3.1 显式公式（可直接放进论文 Methods）

对残差 $r[n,t,c]$（$N$ 个样本、$T=24$、$C$ 个通道），沿预测长度做 **未归一化** rFFT：

$$X_k[n,c]=\sum_{t=0}^{T-1} r[n,t,c]\,e^{-2\pi i k t/T},\qquad k=0,\dots,K-1,\quad K=\lfloor T/2\rfloor+1=13 .$$

单边 Parseval（$T$ 为偶数，Nyquist bin $k=T/2=12$ 存在）：

$$\sum_{t=0}^{T-1} r[n,t,c]^2=\frac{1}{T}\Big(|X_0[n,c]|^2+|X_{T/2}[n,c]|^2+2\sum_{k=1}^{T/2-1}|X_k[n,c]|^2\Big).$$

定义单边权重

$$\omega_k=\begin{cases}1,&k=0\ \text{(DC)}\ \text{或}\ k=T/2\ \text{(Nyquist)},\\[2pt] 2,&1\le k\le T/2-1,\end{cases}$$

则每个频 bin 对 **逐元素 MSE 尺度** 的贡献为

$$c_k=\frac{\omega_k}{N\,T^2\,C}\sum_{n=1}^{N}\sum_{c=1}^{C}|X_k[n,c]|^2,\qquad \sum_{k=0}^{K-1}c_k=\frac{1}{NTC}\sum_{n,t,c}r[n,t,c]^2=\mathrm{MSE}.$$

（`torch.fft.rfft` 默认 `norm="backward"`，即上式的未归一化变换；分母 $N T^2 C$ 正是“Parseval 的 $1/T$”与“MSE 的 $1/(NTC)$”合并的结果。）

频带按 K=13 均分，切点 $e_1=\mathrm{round}(K/3)=4$、$e_2=\mathrm{round}(2K/3)=9$：

$$\mathrm{low}:\ k\in[0,4),\quad \mathrm{middle}:\ k\in[4,9),\quad \mathrm{high}:\ k\in[9,13),\quad \text{edges}=[0,4,9,13].$$

频带贡献 $C_b=\sum_{k\in \text{band }b}c_k$，占比 $s_b=C_b/\mathrm{MSE}$，$\sum_b s_b=1$。

### 3.2 数值校验

对 6 数据集 × 3 seeds 的 test 残差（SAWE 预测）逐对校验：

* `sum(contrib)` 与 `err.pow(2).mean()`（均 float64）的最大相对误差 **2.1×10⁻¹⁶**（全部 < 1e-10；多数为 0 或 1e-16）。
* 三频带贡献之和 == 总贡献 == MSE；`make_bands(13)` 返回 `edges=[0,4,9,13]`，三段互斥且完整覆盖。

## 4. 数据缺口与风险

1. **Electricity 缺失（P0 阻断项）**：`outputs/revision/R1-01/multiseed_Electricity/` 下没有 `predictions/`，无 `preds_val/test.npz` 与 router 权重，故本报告全部为 **6/6** 数据集；论文的 **7/7** 结论只能标为“6/6 已验证，Electricity 待补”。R1-06 的静态基线、R1-07 的 θ 表、R1-09 的占比表都需要在 Electricity 完成后补一行（可直接复用本脚本）。
2. **稿件数值与当前缓存不一致（高优先级）**：用当前 `predictions/` 复算的 SAWE/Equal/Best-single 与稿件 Table 5/9 多处不同，例如 Table 9 的 final MSE（按稿件自身决策）为 0.3825/0.5121/0.1504/0.3865/0.0927/0.1253，本报告（θ=1.2）为 0.3797/0.5031/0.1531/0.4002/0.1046/0.1268；exchange 的 ratio（1.26 vs 1.052）与 ETTm2 的 ratio（1.25 vs 9.844）差异最大。**Table 5、Table 9、Table 10 需要在 R1-01 重跑收尾后统一用当前缓存重生成**，否则 R1-06/07 的数字会与正文自相矛盾。
3. **Best single 的定义在稿件中不统一**：稿件 Exchange/ETTh1 的值对应“val 选出的固定成员”（FL），而 ETTh2 的 0.1624 恰好等于当前缓存中 vanilla 的 test 均值（即“test 上最好的固定成员”）。本报告统一采用 **val-selected**（合法、可复现），并在 1.2 节脚注给出 test-oracle 参考值；回复审稿人时应明确写出这一选择规则。
4. **θ 的事后性风险**：当前缓存不支持“θ=1.2 在 exchange 上移除 FourierFT”，只支持“θ=1.05 才移除”。回复 R1-07/R2-02 时应说明 1.26 的来源（单种子 1.277），并说明 θ=1.2 的决策在 6 个数据集上对 1.05–1.40 的扰动稳定；不要把 exchange 的移除说成 θ=1.2 的先验结果。
5. **统计强度**：n=3 seeds、6 datasets，配对检验功效很低；本报告的“无显著差异”应写成“未观察到可检测的优势”，而非“证明等价”。种子间伪重复使配对 t 检验的 p 值偏乐观，结论以数据集级 Wilcoxon（p=1.00）为准。
6. **静态权重的可识别性**：3 成员单纯形上最优解经常落在边界（11/18 个种子至少一个权重为 0），exchange 上三种子分别退化为 F、混合、FL；这说明“数据集级静态权重”本身方差大，引用时应同时报告逐种子权重（1.3 节）与 mean±std。
7. **未改动任何训练/预测文件**：本报告只读取 `outputs/revision/R1-01/multiseed_*/predictions/`，未写入 `outputs/`，未训练、未改 docx。
